# Manage Qlik Cloud

Manage tenants, access, data, and operational workflows across Qlik Cloud.

## Before you start

You need a **Qlik Cloud tenant** (URL like `yourtenant.region.qlikcloud.com`)
and a way to **authenticate**. For recommended auth patterns and API key security
tradeoffs, see [Authentication: when to use which method](https://qlik.dev/manage/key-concepts#authentication-when-to-use-which-method).

New to Qlik? See [Key concepts](https://qlik.dev/manage/key-concepts) for tenant, space, and
data terms. For a minimal path from credentials to one API call, try
[Your first Manage API call](https://qlik.dev/manage/get-started-first-api-call).
