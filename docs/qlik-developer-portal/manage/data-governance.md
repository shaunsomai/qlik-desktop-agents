# Overview

This section covers Qlik Cloud data governance capabilities that help you make data discoverable, trusted, and reusable.

Catalog metadata, lineage, and data products work together to support data governance in Qlik Cloud.
Catalog and lineage help you understand assets and their dependencies, while data products package
trusted datasets for discovery and consumption in the data marketplace.

## Get started

- [Get started with Catalog integration](https://qlik.dev/manage/data-governance/get-started-catalog) - Create and manage catalog metadata with data stores, assets, and data sets
- [Get started with Lineage integration](https://qlik.dev/manage/data-governance/get-started-lineage) - Retrieve lineage graphs and impact analysis for apps and datasets
- [Create and activate a data product](https://qlik.dev/manage/data-governance/create-data-product) - Package trusted datasets for discovery and consumption in the data marketplace
