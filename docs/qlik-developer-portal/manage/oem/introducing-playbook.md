# Get started with the playbook

> **Note:** This documentation is continuously updated. Feedback is welcome via [Qlik Community](https://community.qlik.com/t5/Official-Support-Articles/The-OEM-amp-ISV-Playbook-How-to-embed-Qlik-Cloud-into-your/ta-p/2485294).

This playbook provides a complete roadmap for integrating Qlik Cloud into your software product.
If you have an OEM or ISV agreement with Qlik and an appropriate subscription type,
follow these steps to ensure a successful implementation.

## Implementation roadmap

### Phase 1: Architecture and planning

**Key deliverables:**

- Technical architecture documentation
- Security and compliance requirements analysis
- Integration approach selection
- Resource and timeline planning

**Activities:**

- **[Solution architecture](https://qlik.dev/manage/oem/solution-architecture/)** - Plan your overall approach
  - [Single vs multiple tenant](https://qlik.dev/manage/oem/solution-architecture/single-multi-tenant) - Choose your deployment model
  - [Embedded vs native experience](https://qlik.dev/manage/oem/solution-architecture/access-route) - Decide how users will interact
    with analytics
  - [Brand Qlik Cloud](https://qlik.dev/manage/oem/solution-architecture/brand-customize) - Customize the look and feel
  - [Data architecture](https://qlik.dev/manage/oem/solution-architecture/data-architecture) - Plan how data will flow into
    Qlik Cloud
  - [Data modeling](https://qlik.dev/manage/oem/solution-architecture/data-modeling) - Design your data model for optimal performance
  - [Design automation](https://qlik.dev/manage/oem/solution-architecture/design-automation) - Plan your automation strategy

### Phase 2: Security and compliance

**Key deliverables:**

- Security architecture documentation
- Compliance requirements mapping
- Data governance policies
- Access control implementation

**Activities:**

- **[Privacy & security](https://qlik.dev/manage/oem/privacy-security/)** - Secure your deployment
  - [Regional deployments](https://qlik.dev/manage/oem/privacy-security/regional-deployment) - Choose where to deploy your data
  - [Data access & deletion](https://qlik.dev/manage/oem/privacy-security/data-access) - Control who can access what data
  - [Encryption & secrets](https://qlik.dev/manage/oem/privacy-security/secrets-encryption) - Protect your data and credentials

### Phase 3: Development and integration

**Key deliverables:**

- Working integration prototype
- Automated deployment pipelines
- Custom branding and theming
- API integrations and data connections
- Qlik Automate workflow templates

**Activities:**

- **[Product development](https://qlik.dev/manage/oem/product-development/)** - Build your product
  - [DTAP environments](https://qlik.dev/manage/oem/product-development/dtap-environments/) - Set up development, test, acceptance,
    and production environments with version control-driven promotion
  - [Structure your applications](https://qlik.dev/manage/oem/product-development/app-architecture/) - Design your app architecture
    for performance and maintainability
- **[Automation development](https://qlik.dev/manage/oem/solution-architecture/design-automation)** - Build tenant provisioning and
  management systems using Qlik Automate workflows
- **Integration testing** - Validate all components work together
- **Workflow template deployment** - Deploy pre-built automation workflows for tenant lifecycle management

### Phase 4: Deployment and operations

**Key deliverables:**

- Production deployment
- Monitoring and alerting systems
- Operational procedures
- Support and maintenance processes

**Activities:**

- **[Management & operations](https://qlik.dev/manage/oem/operate/)** - Manage your deployment
  - [Monitoring](https://qlik.dev/manage/oem/operate/monitoring/) - Keep track of system health and performance
  - [Backup and recovery](https://qlik.dev/manage/oem/operate/backup-recovery) - Protect your data and ensure business continuity
  - [Entitlement management](https://qlik.dev/manage/oem/operate/entitlement-management) - Monitor usage against entitlements
- Production deployment and go-live
- Ongoing maintenance and optimization
