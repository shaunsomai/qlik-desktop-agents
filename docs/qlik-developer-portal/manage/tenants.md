# Overview

Learn how to manage the creation, configuration, and deletion of tenants, which are
the highest level of logical container provided in Qlik Cloud.

> **Note:** Topics relating to the creation of tenants are only relevant to customers with multitenant licenses.
> For more information, review the [multitenant model](https://qlik.dev/manage/platform-operations/overview/#qlik-clouds-multitenant-model).

## Get started

- [Create a tenant](https://qlik.dev/manage/platform-operations/create-a-tenant) - Learn how to create a new tenant on a multitenant entitlement
- [Update tenant name and alias](https://qlik.dev/manage/tenants/update-tenants) - Learn how to update tenant configuration for tenant name and alias hostname
- [Manage tenant encryption](https://qlik.dev/manage/tenants/tenant-encryption) - Learn how to manage tenant encryption using Qlik management APIs
- [Configure access to features in your tenant](https://qlik.dev/manage/tenants/tenant-features) - Learn how to provide users and groups with access to capabilities
- [Configure an email provider](https://qlik.dev/manage/tenants/email-provider) - Configure and test the email configuration in a tenant
- [Delete a tenant](https://qlik.dev/manage/tenants/delete-tenants) - Learn how to delete a tenant from a multitenant entitlement
