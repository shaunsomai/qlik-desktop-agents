# Overview

This section covers migration workflows for moving Qlik applications and related content between environments.
Use these guides for both tenant-to-tenant migrations in Qlik Cloud and migrations from client-managed deployments.

## Get started

- [Migrate apps between Qlik Cloud tenants](https://qlik.dev/manage/migrate/migrate-apps-tenants) - Export and import apps across tenants, including private content and ownership updates
- [Migrate apps from Qlik Sense Enterprise Client-Managed to Qlik Cloud](https://qlik.dev/manage/migrate/qlik-cli-app-objects-migrate) - Move apps and objects from client-managed deployments into Qlik Cloud
