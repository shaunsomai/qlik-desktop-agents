# Analyze Data Connections

Data Connection Analyzer relates connections to applications, owners, users, and reloads, supporting auditing and inventory governance.

## Key points

- Investigate unused, never-used, duplicated, and previously deleted connections.
- Understand where connections are used and widely shared.
- Pair findings with suitable governance or retirement actions.
