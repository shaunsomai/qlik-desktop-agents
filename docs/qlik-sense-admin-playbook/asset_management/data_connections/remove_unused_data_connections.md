# Remove Unused Data Connections

Establish actual dependencies before retiring connections. Repository inventory alone does not provide a complete application-to-connection map.

## Key points

- Compare lineage with evaluated script-log analysis.
- Account for lineage limitations and potential historical-analysis false positives.
- Back up definitions and consider quarantine before removal.
