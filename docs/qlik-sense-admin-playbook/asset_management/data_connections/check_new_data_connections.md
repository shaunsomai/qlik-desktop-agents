# Check for New Data Connections

Review new connections to detect redundancy, understand new sources, and identify additions outside expected processes.

## Key points

- Use the QMC for quick inventory checks.
- The source supplies CLI reporting.
- Use Data Connection Analyzer for deeper dependency and usage analysis.
