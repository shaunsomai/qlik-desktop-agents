# Analyze/Curate Extensions

Combine recent-import review with actual extension usage to reduce maintenance and improve upgrade readiness.

## Key points

- Use the QMC for recent additions.
- Locate application and sheet dependencies with Extension Usage Dashboard.
- Review unused or overlapping extensions and bundled-visualization replacements.
