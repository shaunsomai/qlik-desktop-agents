# Remove Unused Private Sheets

Self-service deployments need a retention approach for personal sheets on published applications. Usage evidence helps control inventory growth.

## Key points

- Use audit activity and Operations Monitor to identify candidates.
- Establish a retention policy and repeatable review.
- The source includes tagging and deletion automation; base and community sheets have separate guidance.
