# Flag Unused Base/Community Sheets

Review base and community sheet usage in published applications to reduce clutter and understand unmet user needs.

## Key points

- Use sheet-activity logging and Operations Monitor as evidence.
- Discuss unused content and community-sheet creation with application owners.
- The source separates identification and tagging from deletion; private sheets have separate guidance.

## Cadence difference

The detail page specifies **Monthly**; the homepage places this under **Quarterly**. Both values are recorded.
