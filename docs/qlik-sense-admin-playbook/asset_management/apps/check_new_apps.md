# Check for New Apps

A regular inventory of recently created applications gives early visibility into new assets and potentially large workloads.

## Key points

- Review creation dates and file sizes in the QMC.
- Operations Monitor provides another inventory view.
- The source describes CLI automation for reporting needs.
