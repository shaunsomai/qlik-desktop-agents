# Review Pinning/Load Balancing

Review engine distribution and whether workloads need dedicated placement. Pinning supports workload isolation and deliberate resource allocation.

## Key points

- Consider separating development, large applications, or business groups.
- Use capacity-planning findings to justify changes.
- Validate availability and placement after modifying rules.
