# Analyze App Metadata Analyzer

App Metadata Analyzer exposes site-wide data-model composition, helping identify modeling problems, memory-heavy applications, and opportunities for deployment standards.

## Key points

- Review synthetic keys, isolated tables, and circular relationships.
- Inspect application, field, and table memory footprints.
- Set suitable thresholds and use findings when reviewing production readiness and engine placement.
