# Analyze App Adoption

Use Operations Monitor to understand application popularity and changing usage. Session totals and distinct-user counts describe different aspects of adoption.

## Key points

- Compare heavily and lightly used applications using both measures.
- Look for sustained trends and recurring peaks.
- Distinguish intensive use by a small group from occasional access by many users.
