# Remove/Quarantine Unused Apps

Identify applications with little or no recent access and assess continuing need. Operations Monitor supplies retirement evidence.

## Key points

- Verify that monitoring data is current.
- Review access dates and publication status to prioritize candidates.
- Use the source retirement or quarantine workflow.
