# Review/Optimize QVDs

Review QVD overlap, growth, and anomalies indicating potential reload-logic problems. The exercise concerns inventory quality rather than optimized read performance.

## Key points

- Include relevant folders in QVD Monitor.
- Maintain reload history to examine trends.
- Use file, row, and column information to investigate inefficiency.
