# Remove Unused Streams

Check that streams contain applications and still serve a purpose. Empty streams can remain after moves or unfulfilled publication plans.

## Key points

- Inspect associated applications in the QMC.
- Assess whether empty streams are reserved or unnecessary.
- The source includes CLI inventory for larger sites.
