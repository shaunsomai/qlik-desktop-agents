# Check for New/Modified Custom Properties

Review property changes to understand resource organization and access control. Excessive or poorly understood values complicate governance.

## Key points

- Clarify new properties with their creators.
- Review modified properties and growth in available values.
- Distinguish security usage from management or automation; the source offers QMC and CLI approaches.
