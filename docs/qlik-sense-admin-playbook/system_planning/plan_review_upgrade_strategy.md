# Plan/Review Upgrade Strategy

Maintain an upgrade strategy and plan for keeping the deployment current, coordinating documentation, milestones, procedures, and validation.

## Key points

- Determine normal upgrades and urgent-change readiness.
- Review release documentation and milestones.
- Establish procedures and validation responsibilities.
