# Review/Update Capacity Plan

Record current usage, expected growth, and justified changes to give owners and budget holders advance notice of capacity needs.

## Key points

- Review licenses, users, system resources, and applications together.
- Document the future state and necessary actions.
- Use the subsections for supporting evidence.
