# Practice Recovery Processes

Exercise the recovery plan using the established recovery mechanism, testing against the agreed time objective.

## Key points

- Adapt the simple or advanced source examples to the site.
- Confirm required resources.
- Feed observed gaps and timings into plan improvements.
