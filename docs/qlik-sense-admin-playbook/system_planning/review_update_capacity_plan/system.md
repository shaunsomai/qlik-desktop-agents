# Capacity Plan: System

Review resource use over time for sustained pressure and future needs. Include user experience alongside measurements.

## Key points

- Review engine CPU, RAM, and concurrent users.
- Examine intra-day reloads and the batch window.
- Investigate recurring pressure and application-level causes of poor performance.
