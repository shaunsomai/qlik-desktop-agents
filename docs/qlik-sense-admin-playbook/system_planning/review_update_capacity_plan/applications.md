# Capacity Plan: Applications

Combine popularity, memory, and model size to identify optimization and dedicated-engine placement candidates.

## Key points

- Use Operations Monitor for usage and App Metadata Analyzer for memory.
- Prioritize popular, resource-intensive applications.
- Consider field optimization, resilient placement, and reporting or on-demand workloads.
