# Capacity Plan: Users

Review activity since the previous exercise to understand adoption changes and anticipate growth.

## Key points

- Record peak concurrency in Operations Monitor.
- Compare users with at least one session and those with at least five.
- Relate patterns to application usage and expected demand.
