# Review Disk Space

Identify storage dependencies and ensure their available capacity is monitored, potentially with an infrastructure team.

## Key points

- Include connection storage locations.
- Review shared Qlik storage and each node's disks.
- Inspect capacity or confirm monitoring by the responsible team.
