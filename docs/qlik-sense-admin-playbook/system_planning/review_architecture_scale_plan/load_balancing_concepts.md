# Load Balancing Concepts

Planning involves proxy traffic distribution, engine-session distribution, and application placement rules.

## Key points

- Proxy balancing needs external infrastructure supporting WebSockets and session affinity.
- Engine distribution operates through the proxy layer.
- Application rules restrict availability to selected engines.
