# Resiliency & High Availability

Distinguish user availability, reload continuity, and whole-site availability. These depend on different roles and infrastructure.

## Key points

- User resilience needs redundant proxy and engine capacity with traffic distribution.
- Reload resilience needs redundant schedulers.
- Whole-site availability also requires resilient database and file storage with failover configuration.
