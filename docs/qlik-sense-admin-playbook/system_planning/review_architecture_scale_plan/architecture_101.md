# Architecture 101 (Components, Terminology)

Understand the services and dependencies composing a Qlik Sense site. Several nodes can share management and licensing.

## Key points

- Hub and QMC provide user and administration interfaces.
- Proxy, Engine, Scheduler, and Repository handle access, computation, reloads, and configuration.
- Repository metadata and shared application storage are key dependencies.
