# Example Production Architectures

Examples illustrate growth from one server to several nodes with separated workloads and increased resilience.

## Key points

- Single-node sites combine roles with limited resilience.
- Separating reload and consumption work protects user experience.
- Larger examples add redundancy and resilient shared dependencies; consult source diagrams.
