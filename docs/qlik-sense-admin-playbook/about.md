# About Qlik Sense Admin Playbook

The playbook offers proactive administration guidance for Qlik Sense Enterprise on Windows. Organizations should adapt it to their deployment rather than treat it as a universal procedure.

## Key points

- Adjust routines and frequency as needs change.
- Review and test configuration changes or cleanup in a non-production environment.
- The playbook is guidance; product and third-party tool support are separate matters.
