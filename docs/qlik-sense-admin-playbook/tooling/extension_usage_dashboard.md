# Extension Usage Dashboard

Extension Usage Dashboard identifies dependencies using application metadata and repository information.

## Key points

- Locate extension objects in applications and sheets.
- Find unused extensions and bundled-visualization replacements.
- Focus upgrade testing and reduce maintenance.
