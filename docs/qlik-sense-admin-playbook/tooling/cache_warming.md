# Cache Warming

Cache warming preloads applications to reduce first-user delay. The guide distinguishes application, session, and calculated-result caches.

## Key points

- Choose frequency and candidates based on activity and engine behavior.
- Compare CacheInitializer, Butler Cache Warming, and Qlik Sense Scalability Tools.
- Review setup, limitations, and session or license constraints.
