# Data Connection Analyzer

Data Connection Analyzer combines evaluated reload logs and repository API information to analyze usage and history.

## Key points

- Relate connections to applications, users, and reloads.
- Support auditing, duplicate detection, and retirement.
- Use project documentation for configuration.
