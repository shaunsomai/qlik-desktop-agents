# Audit User Access

Validate resources users can access and actions they can perform. Auditing examines security-rule outcomes rather than only definitions.

## Key points

- Use QMC Audit for targeted checks.
- The source describes scripted broader analysis.
- Validate before and after rule changes as well as routinely.

## Cadence difference

The detail page specifies **Quarterly**; the homepage places this under **Monthly**. Both values are recorded.
