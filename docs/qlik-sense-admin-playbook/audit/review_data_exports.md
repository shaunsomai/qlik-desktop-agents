# Review Data Exports

Review Excel exports in Operations Monitor to understand demanding workloads and why users take data outside applications.

## Key points

- Exports consume calculation, file-creation, and delivery resources.
- Discuss recurring bulk exports with owners and users.
- Improve application support for analytical workflows.
