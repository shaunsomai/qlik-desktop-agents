# Verify/Execute Backups

Verify recoverable backups of site content and configuration. Adequate coverage needs evidence of successful execution.

## Key points

- Include persistent content, repository PostgreSQL metadata, and certificates.
- Cover ancillary data and deployment-specific configuration.
- Review methods and execution before recovery is required.
