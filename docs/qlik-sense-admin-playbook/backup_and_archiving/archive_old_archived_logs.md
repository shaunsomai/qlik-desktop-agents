# Archive Old Archived Logs

Review old logs to control storage and investigation volume. Archiving or deletion depends on retention obligations and monitoring needs.

## Key points

- Establish retention requirements before cleanup.
- Account for monitoring history requirements.
- The source includes archive and purge automation.
