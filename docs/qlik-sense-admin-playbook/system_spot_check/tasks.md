# Spot-Check: Tasks

Review yesterday's failures to protect application availability. Critical chains and repeated failures deserve deeper investigation.

## Key points

- Filter or sort QMC execution information.
- Assess resources and source policies before business-hour retries.
- The source covers failure notifications.
