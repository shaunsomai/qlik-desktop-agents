# Review 24 Hour Summary (Ops Monitor)

Use the previous day's Operations Monitor summary to assess health and unusual activity.

## Key points

- Review peak CPU and memory with activity timelines.
- Use indicators to find detailed views.
- Evaluate spikes in context and investigate patterns.
