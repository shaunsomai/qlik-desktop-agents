# Sharing contract v1

Install both distinct marketplaces. Agent names do not overlap; skills are plugin-namespaced. Remove the same plugin from the legacy marketplace before replacing it. Inspect full server-qualified MCP names, schemas and target app when both connectors expose qlik_* tools. Cloud uses an external tenant connector; Desktop registers its own loopback connector.

Conventions, theming guidance and themes are vendored within each plugin. Update both copies together and compare hashes. No sibling checkout is required. Preserve existing APPROVED: write protocols. Share QVS models, expressions and themes, mapping QVD connections to the target. Spaces, permissions, automations and credentials remain platform-specific. Desktop reloads cannot validate Cloud section access.

The Markdown reference libraries remain in the original qlik-dev-agents-plugin repository and are not copied into the platform repos. Themes and worked examples stay with each platform; installed packages include the bundled shared assets.
